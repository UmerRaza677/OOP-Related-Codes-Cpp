## 📚 Concepts Covered
* **Encapsulation**: Bundling data and methods into a single unit (Classes).
* **Inheritance**: Creating new classes based on existing ones to reuse code.
* **Polymorphism**: Allowing different classes to respond to the same message in their own way.
* **Abstraction**: Hiding complex implementation details and showing only the essentials.
